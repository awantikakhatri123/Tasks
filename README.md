- Convert Celsius to Fahrenheit

### 2. Callback Hell

- Exam Result Process

### 3. Promises
- Create a Promise with a 2-second delay
- Resolve a Promise with Success
- Reject a Promise and Handle Errors
- Check Even or Odd
- Check Age Eligibility
- Login System
- Check Student Marks
- Shopping Payment
- Check Temperature
- API Simulation

### 4. Promise Chaining
- Add and Multiply Numbers
- Calculate Square
- Double, Add and Multiply
- Check Pass or Fail
- Display User Details
- Calculate Shopping Bill
- Calculate Age
- Multiply, Add and Divide
- Login Verification
- Complete Order System

## Technologies Used
- JavaScript (ES6)
- Callbacks
- Promises
- Promise Chaining
- setTimeout()

The purpose of this practice is to understand JavaScript asynchronous programming concepts and improve problem-solving and coding skills.
